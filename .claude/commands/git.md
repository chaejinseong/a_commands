1. gitignore를 생성(vscode, mac, window)
2. remote이름은 origin으로 push해줘
   주소: git@github.com:chaejinseong/a_commands.git
3. # 적절한 이름으로 commit 메세지를 생성해줘

- commit 메세지 FewShot
- 깃 커밋 규칙
  - \*feat: 새로운 기능 추가
  - \*fix: 버그 수정
  - docs: 문서 수정 (README 등)
  - style: 코드 포맷 변경 (세미콜론, 공백 등)
  - \*refactor: 리팩토링 (기능 변화 없음)
  - test: 테스트 코드 추가/수정
  - chore: 빌드, 설정, 패키지, 기타 작업
  - perf: 성능 개선
  - ci: CI 설정 수정
  - build: 빌드 시스템 수정
  - \*revert: 커밋 되돌리기

4. origin에 push해줘
